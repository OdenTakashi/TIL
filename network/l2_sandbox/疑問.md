# 疑問

2台だと流れがわかりづらい。3台にしたら、「横しか知らない」という Ethernet の仕組みが見えるかもしれない。

A → C に送るとき、A → B → C で送るのではないか。

普段は宛先を知っていて、そこまでバケツリレーするのではないか。

Ethernet ではそれができないのか。

スイッチを通す世界はこうではないか。

```text
A -- スイッチ -- スイッチ -- C
宛先 MAC はずっと C
```

Ethernet はどう知って、スイッチがないと繋がらないのか。

Ethernet は MAC アドレスを詰めて流しているだけではないか。

繋がっているかどうかは、どこでやっているのか。

`send.rb` のどこで宛先を指定しているのか。

引数や変数を略して書いてあると、意味がわからない。

`RawSocket.new` はなぜ必要なのか。

PC 上でやっているから、普段の設定とは違うのではないか。

普段って、スイッチばっかりにならないのか。

ルータとかがスイッチなのか。

ルータは Ethernet を一度外して IP を見て、向こうの線でフレームを作り直す。IP のない世界ならどうするのか。
